Restart Server
Kills and re-spawns the trading process (~5 sec downtime).
⚠ Warning — any active scan, deep dive, or open position sync will be abruptly interrupted. Pending orders in Alpaca are unaffected, but local state (e.g. in-progress take-profit checks) will reset. Only restart if the system appears stuck or after a code update.
Recalibrate Drawdown Baseline
Resets the drawdown high-water mark to the real, current Alpaca balance.
⚠ The drawdown high-water mark only ever ratchets up and nothing resets it automatically — a manual balance change (a deposit, withdrawal, or a deliberate paper-account reset) reads as a catastrophic trading loss and can permanently halt all automated buying. Only use this if a halt genuinely doesn't reflect real trading losses — it fetches your real current Alpaca equity and starts drawdown tracking fresh from there. Does not touch anything else (positions, cash, Day P/L).
